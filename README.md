# Clarify

Clarify is an AI-powered reading experience designed to help you actually understand what you're reading.

It gives users a focused, distraction-free environment to read content, ask questions, and retain more — all in one place.

---

### `$ features`

🧠 AI-Powered Understanding
- Ask questions directly about what you're reading
- Get summaries, explanations, and key insights instantly
- Designed to improve comprehension, not replace thinking

📖 Focused Reading Modes
- Center Stage to highlight the current line
- Tunnel Vision to reduce distractions
- Bionic Reading to guide eye movement and increase speed

🎨 Customizable Experience
- Adjust font size, spacing, and style
- Light and dark mode support
- Clean, minimal interface for long reading sessions

✍️ Annotation Mode (In Progress)
- Highlight and interact with text
- Toggle annotation tools on/off
- Built for active reading and deeper engagement

---

### `$ vision`

Most reading tools optimize for speed or storage.

Clarify optimizes for understanding.

The goal is simple:
> Help people read with focus, retain more information, and feel confident in what they learn.
